# Backend (moved)

This is the backend for the Expense Management app. It was moved to the top-level `backend/` directory.

Quick start

1. Copy `.env.example` to `.env` and set `MONGO_URI` and `JWT_SECRET`.

2. Install dependencies and start server:

```powershell
cd backend
npm install
npm start
```

End points are the same as in the frontend directory's README.
